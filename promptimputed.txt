Deployment Steps Summary
Build locally (npm run build) and upload project files including .next/ (exclude local node_modules).
Configure .env in the project root.
If using Setup Node.js App, set Startup File to server.js and Node 20.
If using Apache / PHP Proxy, visit https://yourdomain.com/cpanel/manager.php?token=YOUR_TOKEN and click Start Server.
Run database migration via https://yourdomain.com/cpanel/db-install.php?token=YOUR_TOKEN.
Add the 10-minute cron job:
bash

php /home/USERNAME/public_html/cpanel/cron-worker.php
